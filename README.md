# TV da Black 2026

TV de vendas da Black Friday ART. A página (GitHub Pages) lê a cada minuto um Apps Script ligado à planilha BLACK 2026, aba `tv_vendas`. O script já entrega as vendas filtradas, sem dado de aluno.

- `index.html`: a TV.
- `config.js`: endereço do Apps Script (`scriptUrl`).
- `apps-script.gs`: código para colar em Extensões → Apps Script da planilha e publicar como App da Web (Executar como: Eu · Acesso: Qualquer pessoa).

Regras: CFP, CFA L1 e Trilha CFG a R$ 3.600 / 4.320; CFP até passar a R$ 5.000 / 6.000; desde 09/10; sem cupom de vendedor = marketing.
